# No-match behavior

When the check finds no positive match, do not send a general recall list, generic warning, or promotional notification. Record the run internally with its timestamp, sources, and no-match result. Remain silent to the user unless the user explicitly asks for the check status.

If asked, say: “I checked the new FDA and USDA notices against the purchases and regular brands you gave me. I did not find a confirmed match. That is not a guarantee that every food is safe—please follow official notices.”
