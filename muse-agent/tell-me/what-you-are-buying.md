# Intake: what you are buying

Treat this as planned shopping, not a confirmed purchase. Capture the product and brand, plus any lot, date code, or store information the user provides. Run an immediate pre-shopping match against current known notices when the integration supports it, and explain that the result is time-bound.

Do not add a planned item to the confirmed purchase log unless the user later says they bought it. If the user says “I usually buy Brand B,” offer to add Brand B to the regular-brand list only when that statement is explicit enough.
